# Quick Reference: POLE Variant Classes

| Feature                          | Classic PPAP (EDM missense)                                  | Early truncation (e.g. p.(Leu53Glnfs\*5))                                             | Reinitiation product (ΔN-POLE, hypothetical)              | Biallelic hypomorphic (FILS / IMAGe-I)    |
| -------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------- | --------------------------------------------------------- | ----------------------------------------- |
| Domains eliminated               | None (point mutation in exo active site)                     | All, if NMD is complete                                                               | N-terminal ~65 aa only; exo, pol, CTD retained            | Varies (splicing, frameshift)             |
| Mutant protein present           | Yes, replicates but cannot proofread                         | Unknown -- NMD vs reinitiation decides                                                | Yes, by definition                                        | Severely reduced or absent                |
| Expected phenotype               | PPAP (polyposis, ultra-hypermutation)                        | None by current consensus [C2, P6]                                                    | PPAP-like only if loss of the Arg37–Phe50 helix that braces the exo domain (9B8S) impairs proofreading; unmeasured | FILS / IMAGe-I (recessive developmental)  |
| Mechanism                        | Defective proofreading, intact polymerization                | See [mechanistic-framework.md](mechanistic-framework.md)                              | Hypothetical: loosened NTD–exonuclease interface → altered pol/exo switching [M3-M5]; PCNA contacts (aa 684–1187) retained | Loss of replication capacity              |
| Viable after somatic loss of WT? | Yes (hypomorph; POLD1 precedent [M1])                        | **No** -- POLE is cell-essential [M10]; a null + LOH tumour cannot exist              | Yes (hypomorph)                                           | N/A                                       |
| TMB                              | 100-1000 mut/Mb; LOH requirement shown for POLD1 [M1], not POLE | Not expected from this allele; if observed, find the other driver (Step 0)         | Could be >100 mut/Mb (untested)                           | Not characterized                         |
| Signature                        | SBS10a/10b ± SBS28 [SIG1, SIG2, SIG4]                        | None from this allele                                                                 | SBS10a/10b predicted                                      | Not characterized                         |
| LOP classification [T2]          | LOP                                                          | Non-LOP (no protein)                                                                  | Would be LOP if proofreading-deficient                    | Non-LOP                                   |
| ICI response                     | EDM 66.7% (2/3) [T1]; LOP ORR 88.9% (8/9) [T2]               | Follows the tumour's actual driver, not the germline allele                           | Unknown; PPAP logic if confirmed                          | N/A                                       |
| CTNA sensitivity [R3, R4]        | Hypersensitive in cell models (Ara-C IC50 3-4x lower)        | Not expected                                                                          | Expected if exo function impaired (untested)              | Not characterized                         |
| Typical ClinVar classification   | Pathogenic / Likely pathogenic                               | 678 truncating records: 44% "Pathogenic" (single-lab, condition "not provided" -- recessive-carrier/blanket-PVS1 logic), 32% conflicting, 21% VUS, 0 B/LB; no concordant P/LP for PPAP (2026-11-22; `scripts/clinvar_lookup.py`) | --                                           | Pathogenic for FILS/IMAGe-I               |
| gnomAD expectation               | Rare                                                         | Present: heterozygous LoF ~0.2% of controls [P6]                                      | --                                                        | Very rare (AR carrier frequency)          |
| Population cancer enrichment     | Enriched in PPAP families                                    | None (0.22% cases vs 0.20% controls) [P6]                                             | --                                                        | N/A (recessive)                           |
| Inheritance                      | Autosomal dominant                                           | Carrier state only (as far as known)                                                  | Would be dominant                                         | Autosomal recessive                       |
| Default germline classification  | P/LP under [C1]                                              | **VUS for PPAP** (PVS1 not applicable [C7]; see variant-interpretation.md Step 4)     | --                                                        | P/LP for FILS/IMAGe-I                     |
